How Does This Percentage Calculator Work?

Enter the initial value and final value. The calculator determines whether the value increased or decreased and shows the exact percentage change.

Percentage Increase or Decrease Formula
Percentage change = (Final Value − Initial Value) ÷ |Initial Value| × 100

Percentage Increase Calculator

Use this calculator to find the percentage increase when a value becomes larger than its original amount. It is useful for prices, salaries, sales, population, marks, measurements, and other numerical changes.

Percentage Decrease Calculator

Use this calculator to find the percentage decrease when a value becomes smaller than its original amount. It can help calculate reductions in prices, expenses, quantities, scores, and other values.

Percentage Change Example

If a value changes from 100 to 125, the difference is 25 and the percentage increase is 25%. If it changes from 100 to 80, the percentage decrease is 20%.

Frequently Asked Questions About Percentage Change

How do I calculate percentage increase?

Subtract the original value from the new value, divide the difference by the original value, and multiply by 100.

How do I calculate percentage decrease?

Subtract the new value from the original value, divide the difference by the original value, and multiply by 100.

What is the difference between percentage change and percentage difference?

Percentage change normally compares a new value with an original value. Percentage difference is commonly used when comparing two values without treating either one as the starting value.

Can I use this percentage calculator for price changes?

Yes. You can use it to calculate percentage increases or decreases in prices, discounts, expenses, sales, wages, and other numerical values.
